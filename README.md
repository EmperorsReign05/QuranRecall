# Quran Recall

A modern Next.js 15 app foundation for memorization health tracking.

## Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- shadcn/ui-style components
- ESLint and Prettier
- Zustand
- Recharts
- Framer Motion

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run format:check
```
